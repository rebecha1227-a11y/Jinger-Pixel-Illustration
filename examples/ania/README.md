# Example Character: Ania

公开填写示例：示范 `character-spec` 怎么填，以及角色包里该有哪些图。

| 文件 | 说明 |
|---|---|
| `character-reference-clean.png` | 干净全身锚点 |
| `character-bust.png` | 半身 |
| `character-sheet.png` | 可选三视图 / 设定板 |
| `character-spec.md` | 文字设定 |

这是**示例角色包**，不是给你当默认试用脸。请创建你自己的 IP，水印用你自己的号。

画风锁仍用仓库 `assets/character/` 里的 Jinger 像素图（只学颗粒和密度，不复制脸和衣服）。
