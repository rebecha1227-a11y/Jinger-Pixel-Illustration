- 脸型 / 五官：年轻女性，大眼深棕，小鼻，浅粉唇，浅桃肤色，脸颊有轻红晕

- 体型比例：纤细；高清像素立绘，不要 Q 版大头
- 帽子：trucker 帽，米色前幅 + 黑帽檐/网面，前幅有 `eee` 字样
- 上衣：浅灰露肩短袖
- 裤子：深色喇叭牛仔裤，大腿做旧/破洞
- 腰带：黑色铆钉腰带 + 银色大扣
- 鞋：厚底黑色短靴
- 耳机：白色无线耳机
- 项链：长黑绳 + 圆环吊坠
- 包：黑色肩包，可有浅棕纹样和白色小挂牌
