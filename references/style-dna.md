# 视觉 DNA

所有用户、所有角色共用。身份来自**当前角色**；画风来自高清像素规则 + 捆绑画风锁。

## 共同

- 高清像素：颗粒细，有轻微体积和抖动阴影。不是 8-bit 大格子、不是简笔画、不是 3D 盲盒、不是写实摄影。
- 当前角色永远同一套记忆点（神态、剪影、标志色/花纹/服装）。角色可以是人、宠物、吉祥物、表情包或品牌 IP，不必须是真人。
- 水印：右下角，小而不抢眼，文案来自当前角色 `character-spec` 的 `watermark`。**排版叠加，禁止让 AI 画。**
- 一张图一个观点。
- **角色不要撑满画面**：清单/介绍页里人只占格子里的一小块；演戏时主体约 40%–60%，留白给物件和字。
- 有字时：**标签贴在对应物件正下方或物件上**，图文成对。不要左边一列字、右边一个大人。
- 图内文字写进 prompt，按这一张需要：
  - 演戏 / 一个观点：2–6 字贴在物件上，能不加就不加
  - 封面 / 知识卡：短句，见卡片预算
  - 列步骤 / 清点成品：编号短句 + 小图标成对，见 `explainer-workflow.md`
- 水印永远后盖。平台自动水印（如豆包）不管。

身份参考优先级：干净全身 > 三视图（如有）> 半身 > 文字 spec > 画风锁。**画风锁不能盖过「这是谁」。**

抽象知识怎么入画：先读 `concept-visual-language.md`，写短 visual plan 再拼 prompt。

## 画风锁

捆绑参考图只负责「像素长什么样」，不负责「用户是谁」。

| 用途 | 路径 | 怎么用 |
|---|---|---|
| 角色像素密度 | `assets/character/jinger-pixel-bust.png` + `jinger-pixel-fullbody.png` | 创建/转换角色、以及非示范身份出图时传入，只学颗粒、描边、上色 |
| 封面/卡片场景气质 | `assets/style-lock/warm-pixel-scene-16x9.png` | 只给封面和知识卡学桌面/边框/暖色；正文图不要学它的高信息密度 |
| 示范设定（给人看，不默认启用） | `examples/jinger/` | 作者示范；开源用户不要设成当前角色 |

规则：

- 当前角色**不是**这套示范身份 → 只学画风，不要复制画风锁图里那个人的脸、帽、衣服。
- 当前角色**就是**这套示范身份（仅作者本地已确认）→ 身份和画风都可以用这些图。
- 三视图 `jinger-turnaround.png` 只用来核对角和配件，不锁画风。

## 长文 16:9

一套必须同时有：

1. 封面 / 主题背景 × 1
2. 正文解释图 × 按信息密度（见 `article-workflow.md`）

| 用途 | 背景 | 密度 |
|---|---|---|
| 封面 / 主题 | 暖色简单像素场景：奶油纸 / 浅木桌 / 软木板，可加深棕像素细边框；桌上 1–3 小物件 | 可稍满：人物 + 少量信息块 + 桌面 |
| 正文解释 | **默认白底迷你剧场**：白底 + 一点点像素地面/接触阴影 | 物件 1–3；主体约 50%–65% |

禁止：写实风景、完整大房间巡游、霓虹 HUD、Vox 黄黑拼贴、PPT SmartArt、正文图塞成白皮书海报。

**流程拆解**（解释一个机制时）：3–5 节点；角色可分身，每个分身都在做事；从左到右，要透气。  
**核心动作**：一个角色 + 一个核心物件 + 一个动作 + 一个可见结果。角色必须参与核心关系，去掉角色图就不成立。

若这一张的内容就是在列步骤 / 清点成品，把 `explainer-workflow.md` 里的排法写进 prompt，不要空荡荡只站两个人。

## 知识卡片 3:4

- 画幅 3:4。整张由生图模型一次画完，像一幅竖着的像素插画，不是排版海报。
- 气质对齐暖色场景锁：奶油纸 / 浅木桌 / 软木板，可加深棕细边框。
- 点缀色用该角色 `accent_colors`
- 角色必须生活在场景里，和短文字块一起演戏。禁止只站着指板子。
- 英文像素标题仅封面 + 至多 1 张强调页；其他页用完整短句，不要只剩两个字。
- 步骤/对比页：必须有 ①②③ 或左右对照，文字预算见 `card-templates.md`
- 禁止：HTML 杂志排版感、纯文字堆叠、Vox 拼贴、深色 Game Boy 整屏、PPT SmartArt
