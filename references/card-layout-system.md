# 知识卡 · 版式系统（Layout System）

固定信息设计规则 + **按内容类型可变的版式**。  
要的是：固定 Style + 可变 Layout；不是「固定一张模板换字」。

## 通用层级（单卡可裁剪）

1. **HERO TITLE** — 最强；英文关键词可用大号复古像素字；中文说明用清晰可读字体  
2. **INTRO / CORE IDEA** — 标题下 1–2 句，短  
3. **MAIN MODULES** — 按内容类型 1–5 块（多卡系列每张通常 1–2 块）  
4. **CHARACTER INTERACTION** — 角色必须参与讲解（见 `card-character-system.md`）  
5. **KEY TAKEAWAY** — 结论框，短、好记、框更强  
6. **MICRO DETAILS** — 箭头/文件夹/清单 UI 等，不得抢信息  

留白要故意留；不要填满每个空隙。角色不要压住关键文字。四边干净边距。

## 按内容类型选型（LAYOUT ADAPTATION）

| 类型 | 版式 |
|---|---|
| concept 概念解释 | 中心定义 + 3–5 支撑模块 |
| comparison 对比 | 双栏 / 对切 VS |
| process 流程 | 编号流程图 + 方向箭头 |
| framework 框架 | 分层卡片 / 节点连线 / 模块块 |
| tutorial 教程 | 顺序编号分镜条 |
| list 清单 | 带图标的叠卡列表 |
| timeline 时间线 | 纵/横时间轴 |
| cause-effect 因果 | 节点 + 方向箭头 |
| architecture 技术结构 | 文件夹 / 文件 / 界面 / 连接器 |
| abstract 抽象 | 强视觉隐喻 + 角色互动 |

禁止强行把每篇文章塞进同一种模板。

## 多卡系列 vs 单卡深讲

- **多卡系列（默认 6–8）**：每张只回答一个小问题；模块少、字少、层级仍完整（标题→演示→结论感）。  
- **单卡深讲**：用户明确只要 1 张总览时，可用完整 4–7 块结构（对齐 style-lock 样例密度）。

页型标签（cover / pain / concept / steps / compare / pitfall / cta）见 `card-templates.md`，用于 shot list；真正构图按上表选型。
