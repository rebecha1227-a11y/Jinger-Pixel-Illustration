# 创建 / 导入角色

没有 `confirmed` 角色时读本文件。配图前必须走完确认门闩。

禁止给使用者「试用示范角色 / 启用内置角色」。捆绑像素图只作画风锁 + 作者示范，见 `style-dna.md`。

填写设定时用 `references/character-spec.md` 模板。作者示范见 `examples/jinger/`；公开填写示例见 `examples/ania/`。

角色不一定是真人。用户可以拿**有权使用**的参考素材做成高清复古像素 IP：真人照、宠物、表情包、动漫角色、品牌吉祥物等。重点是抓住**神态和记忆点**，不是做成写实照片。

## A. 导入现成形象

用户发来已经是「角色/IP 图」的素材（像素图、插画、设定板、吉祥物设计稿、全身/半身都算）。

1. 判断类型：
   - **已经是高清像素** → 提炼特征，补齐缺失资产（至少干净全身或等价主锚点 + `character-spec.md` + 半身/头身）
   - **非像素插画 / 三视图 / 吉祥物设计** → 以它为身份参考，转成高清像素。画风锁用 `assets/character/jinger-pixel-bust.png` 与 `jinger-pixel-fullbody.png`，只锁颗粒和密度，**不要复制画风锁图里那个人的脸和衣服**
   - **真人照、宠物照、表情包原图、随手拍** → 改走 B，不要当成现成形象糊弄过去
2. 一次问完：角色名、水印（可跳过，默认 `@角色名`）、气质词 3 个以内（可选）、`character_type`
3. 生成干净全身（或约定的主锚点）+ 半身/头身 + spec，状态 `draft`
4. 停下来等人确认，并问要不要可选三视图

## B. 从参考素材创建

创建前必须把「参考素材要求」展示给用户，并先认一下素材类型。

### 参考素材要求

**所有类型都要**

- 只用自己的，或已获授权的素材。禁止明星脸、网图路人、未授权就把别人的商业 IP 当成自己的号
- 画面里**只有一个主角**；不要合影抢镜
- 能看清记忆点：神态、剪影、花纹、标志色、标志配件
- 第一版只锁这一套标志特征，不要一次丢很多完全不同的造型

**按类型**

| 类型 | 必须 | 最好再补 | 不要 |
|---|---|---|---|
| 真人 | 正面能看清五官和发型；尽量全身或膝盖以上，能看清衣服/鞋/包 | 侧面、背面、标志配件特写 | 重度美颜磨平脸；大逆光；墨镜挡完眼睛又没有露眼图（除非墨镜就是固定造型） |
| 宠物 | 脸和花纹清楚；尽量能看清体型、毛色、标志斑块 | 侧面、背面、标志表情 | 严重逆光、糊成一团、好几只抢镜 |
| 表情包 / 贴纸 | 标志表情和剪影清楚 | 同一角色的 2–3 个表情 | 马赛克、字把脸挡死 |
| 动漫 / 插画角色 | 尽量正面全身；发型、瞳色、服装能看清 | 三视图或背面 | 只有一张局部、认不出是谁 |
| 品牌 IP / 吉祥物 | 标志色、剪影、和 Logo 的关系清楚 | 多角度、官方色值 | 擅自改品牌色（除非用户明确要求） |

表情包如果**只有头/半身**：先问「这套 IP 以头身表情为主，还是要补一个全身造型？」不要偷偷编一套衣服。

缺关键记忆点时：**停下来要图**，不要硬脑补。

### 一次问完的事

1. 角色名（中文或英文）
2. 水印（每张成品右下角）。没有就用 `@角色名`
3. 气质关键词 3 个以内（可选）。不猜职业、年龄、敏感属性
4. `character_type`：human / pet / mascot / anime / brand / meme（根据素材判断，拿不准就问一句）

### 生成风格

> 高清复古像素角色。颗粒细，有轻微体积，像独立游戏角色立绘，不是 8-bit 大格子，不是简笔画，不是 3D 盲盒，不是写实摄影。

身份必须从参考素材来：神态、签名剪影、标志色、花纹/配件，以及素材里**已经出现**的身体和服装。只保留看得见的记忆点，不要发明素材里没有的东西（除非用户明确要求补全身）。

画风锁：`assets/character/jinger-pixel-bust.png` + `jinger-pixel-fullbody.png`。只学像素密度、描边、上色；不要复制画风锁图里那个人的脸、帽、衣服。

## 角色包

| 文件 | 要求 | 是否必须 |
|---|---|---|
| `character-reference-clean.png` | 干净主锚点：纯白或透明底，单主体，无标题、无边框、无四视图、无色板。默认全身；表情包头身 IP 可以是完整头身锚点 | **必须** |
| `character-bust.png` | 干净半身/头肩（宠物=头身特写），锁脸/神态和头上的标志特征 | **必须** |
| `character-spec.md` | 按模板：类型 + 可观察特征 + 角色名 + 水印 + 气质词 + accent_colors + 签名剪影。不写猜测信息 | **必须** |
| `character.json` | 由 `scripts/character_registry.py register` 生成 | **必须** |
| `character-sheet.png` | 竖版三视图/设定板：主全身 + 正面 / 左侧 / 背面 / 右侧。仅设定板可用浅底和方向标签 | **可选** |

干净参考图不得复制设定板排版。

## 可选三视图

像素角色（主锚点 + 半身/头身）出来之后，**加问一句**（确认不依赖它）：

```text
要不要再出一套角色三视图 / 设定板？可选。
正面 + 侧面 + 背面，方便以后画侧面/背面，也可以当设定图分享。
不要也不耽误确认和配图。
```

- 用户说要 → 用 `prompt-templates.md` 里的三视图骨架生成 `character-sheet.png`，再 `attach-sheet` 或 register 时带上 `--sheet`
- 用户说不要 / 先跳过 → 只靠主锚点 + 半身/头身确认即可
- 确认之后才想要 → 仍然可以补做，不撤销 confirmed
- 表情包头身 IP：三视图仍然可选；没有全身就不要硬做四视图全身

三视图必须彼此一致，并和主锚点同一身份、同一套记忆点。

## 确认门闩

- 展示主锚点 + 半身/头身（有三视图就一起展示），问：确认，还是改哪一处？
- 一次只改一个主要问题（先改神态，或先改一个记忆点）
- 旧文件不覆盖，存 `-v2` `-v3`
- 未说「确认 / 定稿 / 就用这个」之前：不能配长文、不能做知识卡片、不能设为当前角色
- 同时丢了素材和文章：先创建并停在确认，不要提前配图
- 没有三视图也可以确认

无生图时：仍写出 `character-spec.md` 草稿 + 主锚点/半身（及可选三视图）的 prompt + 素材检查结果，等人家出图后再 `register` / `confirm`。
