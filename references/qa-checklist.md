# QA 清单

过不了就重来或改模板，不要凑合交付。

1. 是不是高清像素，而不是简笔画 / 3D 公仔 / 8-bit / 写实照片？
2. 当前角色是不是同一张脸、同一身衣服、同一标志配件？
3. 当前角色不是 Jinger 时，有没有误画成 Jinger？
4. 长文套图是否同时有封面 + 正文图？封面是不是暖色简单像素场景？正文是不是白底迷你剧场、一张一个观点？
5. 卡片是不是一整张暖色像素插画？角色是否生活在场景里？有没有做成 HTML 排版海报？
6. 图内中文是否短、少、写对？有没有塞进段落？水印是不是后盖而不是 AI 画的？
7. 英文像素标题是不是只在封面/强调页？
8. 右下角水印是不是**当前角色自己的文案**，小而不抢眼？
9. 一张图是不是只讲一件事？
10. 成图有没有误带设定板标题、四视图、色板？
11. 未确认的 draft 角色有没有被拿去配图？（有则违规）
12. 知识卡片是否 ≤ 9 张？长文正文是否 ≤ 8、整套 ≤ 9？
