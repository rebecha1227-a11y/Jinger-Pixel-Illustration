# QA 清单

每张图先走**角色包对照审核**，再走必查。过不了就 REVISE 或 REGENERATE，不要凑合交付。

一套图再并排看系列 + 缩略图。

## 角色包对照审核（出图后强制，先做）

把成品和当前角色包**逐项对照**。有角色出场的图必须做；说明图无人可标 N/A。

对照源（全部打开看，不要只瞄一张全身）：

- [ ] `character-reference-clean.png`（全身比例、服装、剪影）
- [ ] `character-bust.png`（脸、神态、发型近景、头配件）
- [ ] `character-sheet.png`（若有：三视图角度、配饰特写、色板颜色）
- [ ] `character-spec.md`（签名剪影、允许/禁止改、记忆点文字）

逐项勾：

- [ ] 脸型 / 五官 / 神态记忆点一致（半身图优先裁决脸）
- [ ] 发型与头饰一致（长短、分束、绑法；禁止漂成高双马尾/丸子等未登记造型）
- [ ] 眼睛颜色与标志细节（痣、耳饰、耳机位置等）一致
- [ ] 上衣 / 下装 / 鞋靴一致（颜色、版型、花纹）
- [ ] 标志配饰一致（包、耳机、领结等；sheet 特写有的要能对上）
- [ ] 体型比例一致（不要突然 Q 版大头或写实长腿）
- [ ] 像素密度与描边和角色包一致（不是滤镜假像素）
- [ ] **没有**误画成画风锁/样例图里的另一个角色（Ania、示范 Jinger 等）

任一项明显漂了 → **REGENERATE**（或只修角色的局部重绘），不要用「构图还行」交货。

## 必查（每张）

- [ ] 高清像素，不是简笔画 / 3D 公仔 / 8-bit / 写实照片
- [ ] 已通过「角色包对照审核」（或无人说明图已标 N/A）
- [ ] 一个主观点；和本套其他图职责不重复；视觉比喻能讲清这件事
- [ ] 长文：有封面+正文；封面对齐 warm-pixel-scene；正文对齐 article-body-editorial（底色可与封面不同）；普通观点可迷你剧场但气质跟正文锁；**清单/步骤/对比走说明图**
- [ ] 同一篇文章的正文图：统一底色、边框、像素风格（封面不必跟正文同一底）
- [ ] 卡片：米白/暖棕几乎纯色底 + 编辑式像素信息图（RPG UI 模块）；对齐 knowledge-card style-lock，不是复杂房间剧场，不是 HTML 杂志贴图，不是呆站装饰
- [ ] 卡片流程：走过 CONTENT→LAYOUT→STYLE→CHARACTER→IMAGE 流水线；内容来自原文；不是空想
- [ ] 生图：优先 edit-from-package（角色包底图改姿态）；传入 clean+bust+（若有）sheet 且读过 spec；不是只塞一张全身从零发明
- [ ] 卡片角色：讲解者有互动；占位约 1/4～1/3；全身/半身按本张排版与文字互动选择（shot list 有 CROP 理由）；没有撑满
- [ ] 卡片信息密度：模块含必要短说明，不是「三行钩子+巨大角色」；无模型发明的 tip/优缺点列表
- [ ] 禁止因超时砍掉原文模块或身份锁后仍当合格品交付
- [ ] 图内字按模式够用：说明图/步骤卡必须是完整短句+编号或箭头；没有段落；水印是后盖，不是 AI 画的；禁止「豆包AI生成」- [ ] 英文像素标题只在封面/强调页
- [ ] 没有误带设定板标题、四视图、色板框进成图
- [ ] 不是 draft 角色在配图
- [ ] 卡片 ≤ 9；长文正文 ≤ 8、整套 ≤ 9

## 长文正文额外

迷你剧场：去掉角色，图就不成立。封面可以更像主角出场，但仍要和钩子有关。  
说明图：不要求每格都有人；画风气质对齐 `article-body-editorial-16x9.png`。

## 流程说明图额外（步骤 / 清单 / 对比）

过不了就 REGENERATE，不要当成「画风还可以」交货：

- [ ] 有大标题，能看出这张在回答什么
- [ ] 有 ①②③ 或中间大箭头，不是只靠并排站着
- [ ] 每步是 6–16 字完整短句，不是两字碎标签
- [ ] 图内中文和 visual plan.exact_labels 一致，没有同义改写
- [ ] 一步一个格子；没有 1/2/3 共用一块拼贴
- [ ] 字够大；角色没有撑满；能用图标/箭头说清的格子没有硬塞人
- [ ] 若有序号：整张只出现一轮，没有每行重复全套 ①②③④
- [ ] 宽图是扁横图、竖卡是竖的；标签贴在对的物件上；画中画在框内
- [ ] 原材料看起来像照片/文稿/贴纸，不是已经做好的像素肖像；同一句标签不出现两次
- [ ] 可选项写成 `A / B / C`；缩略图里标题和步骤仍可读

## 一套图再查

并排看同一篇文章 / 同一套卡：

- [ ] 同一角色、同一身、同一像素密度、同一世界观（再扫一遍角色包对照）
- [ ] 长文正文图统一底色、边框、风格；封面可以不同
- [ ] 每张 job 不同，没有两张图在讲同一件事
- [ ] 缩成缩略图：还能认出这个角色，主观点还在，字不会糊成一块

失败就简化构图，不要加更多字。

## 判定

**PASS**：角色包对照通过、画风对、观点清楚、构图能读、水印对、字可接受。

**REVISE**：局部问题（某个标签、某个物件、轻微构图），可针对性重画或后处理。

**REGENERATE**：脸/发型/服装漂了、画风错了、概念画错了、构图彻底坏了、误画成别人。

同一张最多针对性重试 2 次。

## 修复顺序

1. 角色身份（对照整包）  
2. 概念有没有画对  
3. 像素画风  
4. 构图  
5. 图内文字 / 水印  

一张很好看但画错角色或画错观点的图，仍然不合格。
