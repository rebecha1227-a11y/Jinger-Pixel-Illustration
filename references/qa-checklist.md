# QA 清单

每张图先走**必查**。过不了就 REVISE 或 REGENERATE，不要凑合交付。

一套图再并排看系列 + 缩略图。

## 必查（每张）

- [ ] 高清像素，不是简笔画 / 3D 公仔 / 8-bit / 写实照片
- [ ] 同一套记忆点（神态、剪影、标志色/花纹/服装）；没有误画成画风锁示范角色（当前角色不是该示范时）
- [ ] 一个主观点；和本套其他图职责不重复；视觉比喻能讲清这件事
- [ ] 长文：有封面+正文；封面是暖色简单像素场景（底色可与正文不同）；普通正文是迷你剧场；**清单/步骤/对比走说明图，不是迷你剧场**
- [ ] 同一篇文章的正文图：统一底色、边框、像素风格（封面不必跟正文同一底）
- [ ] 卡片：整张暖色像素插画，角色生活在场景里，不是 HTML 排版海报，也不是呆站指板子
- [ ] 图内字按模式够用：说明图/步骤卡必须是完整短句+编号或箭头；没有段落；水印是后盖，不是 AI 画的；禁止「豆包AI生成」
- [ ] 英文像素标题只在封面/强调页
- [ ] 没有误带设定板标题、四视图、色板
- [ ] 不是 draft 角色在配图
- [ ] 卡片 ≤ 9；长文正文 ≤ 8、整套 ≤ 9

## 长文正文额外

迷你剧场：去掉角色，图就不成立。封面可以更像主角出场，但仍要和钩子有关。  
说明图：不要求每格都有人。

## 流程说明图额外（步骤 / 清单 / 对比）

过不了就 REGENERATE，不要当成「画风还可以」交货：

- [ ] 有大标题，能看出这张在回答什么
- [ ] 有 ①②③ 或中间大箭头，不是只靠并排站着
- [ ] 每步是 6–16 字完整短句，不是两字碎标签
- [ ] 图内中文和 visual plan.exact_labels 一致，没有同义改写
- [ ] 一步一个格子；没有 1/2/3 共用一块拼贴
- [ ] 字够大；角色没有撑满；能用图标/箭头说清的格子没有硬塞人
- [ ] 若有序号：整张只出现一轮，没有每行重复全套 ①②③④
- [ ] 宽图是扁横图、竖卡是竖的；标签贴在对的物件上；画中画在框内
- [ ] 原材料看起来像照片/文稿/贴纸，不是已经做好的像素肖像；同一句标签不出现两次
- [ ] 可选项写成 `A / B / C`；缩略图里标题和步骤仍可读

## 一套图再查

并排看同一篇文章 / 同一套卡：

- [ ] 同一角色、同一身、同一像素密度、同一世界观
- [ ] 长文正文图统一底色、边框、风格；封面可以不同
- [ ] 每张 job 不同，没有两张图在讲同一件事
- [ ] 缩成缩略图：还能认出这个角色，主观点还在，字不会糊成一块

失败就简化构图，不要加更多字。

## 判定

**PASS**：身份对、画风对、观点清楚、构图能读、水印对、字可接受。

**REVISE**：局部问题（某个标签、某个物件、轻微构图），可针对性重画或后处理。

**REGENERATE**：脸漂了、画风错了、概念画错了、构图彻底坏了、误画成别人。

同一张最多针对性重试 2 次。

## 修复顺序

1. 角色身份  
2. 概念有没有画对  
3. 像素画风  
4. 构图  
5. 图内文字 / 水印  

一张很好看但画错角色或画错观点的图，仍然不合格。
