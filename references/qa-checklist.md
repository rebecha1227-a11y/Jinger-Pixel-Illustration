# QA 清单

每张图先走**必查**。过不了就 REVISE 或 REGENERATE，不要凑合交付。

一套图再并排看系列 + 缩略图。

## 必查（每张）

- [ ] 高清像素，不是简笔画 / 3D 公仔 / 8-bit / 写实照片
- [ ] 同一套记忆点（神态、剪影、标志色/花纹/服装）；没有误画成画风锁示范角色（当前角色不是该示范时）
- [ ] 一个主观点；视觉比喻和角色动作能讲清这件事
- [ ] 长文：有封面+正文；封面是暖色简单像素场景；普通正文是白底迷你剧场；**怎么用/清单类走说明图，不是迷你剧场**
- [ ] 卡片：整张暖色像素插画，角色生活在场景里，不是 HTML 排版海报，也不是呆站指板子
- [ ] 图内字按模式够用：说明图/步骤卡必须是完整短句+编号或箭头；没有段落；水印是后盖，不是 AI 画的；禁止「豆包AI生成」
- [ ] 英文像素标题只在封面/强调页
- [ ] 没有误带设定板标题、四视图、色板
- [ ] 不是 draft 角色在配图
- [ ] 卡片 ≤ 9；长文正文 ≤ 8、整套 ≤ 9

## 长文正文额外

去掉角色，图就不成立。封面可以更像主角出场，但仍要和钩子有关。

## 流程说明图额外（怎么用 / 提供得到 / 你会拿到什么）

过不了就 REGENERATE，不要当成「画风还可以」交货：

- [ ] 有大标题，能看出这张在回答什么
- [ ] 有 ①②③ 或中间大箭头，不是只靠并排站着
- [ ] 每步是 6–16 字完整短句，不是「素材/确认/出图」两字
- [ ] 具体列出提供了什么、得到了什么（真人照/文章/Logo ↔ 像素角色/16:9/3:4）
- [ ] 角色每步换动作、换道具；禁止全程站直指软木板
- [ ] 「得到」侧能认出是这个角色的像素 IP + 配图/卡片，不是无关风景或假英文卡
- [ ] 一步一个格子；没有 1/2/3 共用一块拼贴
- [ ] 16:9 是扁横图，3:4 是竖卡，全身/半身是白底立绘；标签不贴错物件
- [ ] 「提供」侧不是已经做好的像素肖像；同一句标签不出现两次
- [ ] 字够大；缩略图里标题和步骤仍可读

## 一套图再查

并排看同一篇文章 / 同一套卡：

- [ ] 同一角色、同一身、同一像素密度、同一世界观
- [ ] 缩成缩略图：还能认出这个角色，主观点还在，字不会糊成一块

失败就简化构图，不要加更多字。

## 判定

**PASS**：身份对、画风对、观点清楚、构图能读、水印对、字可接受。

**REVISE**：局部问题（某个标签、某个物件、轻微构图），可针对性重画或后处理。

**REGENERATE**：脸漂了、画风错了、概念画错了、构图彻底坏了、误画成别人。

同一张最多针对性重试 2 次。

## 修复顺序

1. 角色身份  
2. 概念有没有画对  
3. 像素画风  
4. 构图  
5. 图内文字 / 水印  

一张很好看但画错角色或画错观点的图，仍然不合格。
