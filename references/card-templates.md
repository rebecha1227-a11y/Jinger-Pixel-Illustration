# 知识卡片构图配方

这些是**生图时的构图类型**，不是要套的 HTML 版式。一套从中选 6–9 张。

`templates/*.html` 仅无生图且用户要求占位时使用，气质偏硬，不是目标。

| 页型 | 干什么 | 角色在像素场景里怎么演 |
|---|---|---|
| 封面 cover | 一句话钩子 | 和标题牌互动：扶着、托着、从桌上拿起，不要只指着 |
| 痛点 pain | 读者卡在哪 | 被痛点牌挡住，或推开「卡住了」木牌 |
| 概念 concept | 一个判断/地图 | 举起完整短句牌，或站在 2–4 个结构节点上搬运物件 |
| 步骤 steps | 3–5 步怎么做 | 分身逐步做事；每步有 ①②③ 和完整短句，动作必须不同 |
| 对比 compare | 错 vs 对 | 站在「对」的一边，推开「错」的一边；两边都有名牌 |
| 避坑 pitfall | 常见误区 | 拦住、剪断、挡住错误做法 |
| 立刻试 cta | 现在就能做的小动作 | 把一张小 CTA 卡或按钮递出来 |

封面必有。最后一页默认 cta。

## 图内文字预算

- 封面：1 个短英文像素标题（可无）+ 1 句中文副标题（6–14 字）+ 可选 1 条 banner（≤8 字）
- 步骤 / 对比 / 概念页：每条 **6–14 字完整短句**，必须带 ①②③ 或左右名牌；全图 4–8 条。禁止整页只有「素材/确认/出图」这种两字
- 其他页：短句 4–12 字，全图不超过 8 条
- 字要大、要能读。不要段落、不要小字说明书、不要把文章贴进图里

若这一页其实是「Skill 怎么用 / 你会得到什么」，改走 `explainer-workflow.md`，不要当普通知识卡硬挤。

## 场景

暖色简单像素场景：奶油纸 / 浅木桌 / 软木板，可加深棕细边框。桌上可有电脑、杯子、书等 1–3 个物件。对齐 `assets/style-lock/warm-pixel-scene-16x9.png` 的气质，但竖构图、信息更少。
