# 知识卡片构图配方

这些是**生图时的构图类型**，不是要套的 HTML 版式。一套从中选 6–9 张。

`templates/*.html` 仅无生图且用户要求占位时使用，气质偏硬，不是目标。

| 页型 | 干什么 | 角色在像素场景里怎么演 |
|---|---|---|
| 封面 cover | 一句话钩子 | 站在暖色桌面/纸板前，和短英文标题或中文副标题互动 |
| 痛点 pain | 读者卡在哪 | 被某句痛点卡住，或指着一块「问题」木牌 |
| 概念 concept | 一个判断/地图 | 举起关键词牌，或站在 2–4 个结构节点上 |
| 步骤 steps | 3–5 步怎么做 | 分身或依次推动步骤块 / 传送小物件 |
| 对比 compare | 错 vs 对 | 站在「对」的一边，推开「错」的一边 |
| 避坑 pitfall | 常见误区 | 拦住、剪断、挡住错误做法 |
| 立刻试 cta | 现在就能做的小动作 | 把一张小 CTA 卡或按钮递出来 |

封面必有。最后一页默认 cta。

## 图内文字预算

- 封面：1 个短英文像素标题（可无）+ 1 句短中文副标题 + 可选 1 条 banner（≤8 字）
- 其他页：中文标签每条 2–8 字，全图合计不超过 6–8 条
- 不要段落、不要小字说明书、不要把文章贴进图里

## 场景

暖色简单像素场景：奶油纸 / 浅木桌 / 软木板，可加深棕细边框。桌上可有电脑、杯子、书等 1–3 个物件。对齐 `assets/style-lock/warm-pixel-scene-16x9.png` 的气质，但竖构图、信息更少。
