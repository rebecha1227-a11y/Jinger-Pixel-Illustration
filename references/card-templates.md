# 知识卡片页型（Shot list 用）

页型用于**拆多卡系列**，不是生图时死套的 HTML。  
真正构图按 `card-layout-system.md` 的内容类型选型。

| 页型 | 干什么 | 讲解者怎么演（示例） |
|---|---|---|
| 封面 cover | 一句话钩子 | 捧着主题物件 / 掀开标题模块，人小标题大 |
| 痛点 pain | 读者卡在哪 | 推开「卡住了」模块，或坐在混乱清单旁对比 |
| 概念 concept | 一个判断/定义 | 举起定义框、指向中心物件 |
| 步骤 steps | 3–5 步 | 沿编号流程移动；每步 ①②③ 完整短句 |
| 对比 compare | 错 vs 对 | 站在「对」侧，或分身出现在双栏 |
| 避坑 pitfall | 常见误区 | 拦住、剪断错误做法 |
| 立刻试 cta | 下一步小动作 | 递出 CTA 模块 |

封面必有。最后一页默认 cta。

## 图内文字预算

- 封面：大标题 + 1 句副标题 + 可选短 banner  
- 步骤 / 对比 / 概念：每条 **6–14 字完整短句**；全图通常 4–8 条。禁止整页只有两字碎标签  
- 单卡深讲：模块可更多，但仍短句，不要贴文章段落  
- 字要大；术语保留原文（SKILL.md 等）

## 场景（已纠正）

- **几乎纯色**暖米白底 + RPG/像素 UI 模块  
- 对齐 `assets/style-lock/knowledge-card-editorial-3x4.png`  
- **不要**奶油桌+软木板+满屋道具的房间剧场（那是旧版错误方向）
