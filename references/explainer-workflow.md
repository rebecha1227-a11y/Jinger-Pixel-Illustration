# 清单 / 介绍页怎么写进 prompt

当**这一张的内容**就是在列步骤、清点成品、对比「你提供 / 你得到」时，用下面的排法写进生图 prompt。

若这一张是在演戏、介绍一个概念、画一串动作：不要用这种排法。把动作、物件、少量标签写进 prompt 即可，见 `article-workflow.md` / `prompt-templates.md` 的迷你剧场写法。

选哪种排法，看这一张要让人看懂什么，写进 prompt；不是系统里有一个默认开关。

Fish 类说明图能看懂，是因为**信息设计**，不是因为简笔画更好看。我们学它的结构，不学它的 doodle 画风。

## 和另外两种模式的差别

| | 长文正文 | 知识卡片 | **流程说明图（本文件）** |
|---|---|---|---|
| 目的 | 讲清一个观点 | 一页一个知识点 | 让人看懂步骤或清单 |
| 文字 | 极少，2–6 字 | 短句，见卡片预算 | **编号短句 + 物件名牌**，必须够读 |
| 箭头/序号 | 尽量少 | 步骤页可用 | **必须有 ①②③ 或箭头** |
| 角色 | 演这一个观点 | 和文字互动 | **每一步换动作、换道具** |
| 失败样 | — | HTML 海报 | 呆站指板子；只有「提供/得到」两个字 |

仍禁止：PPT SmartArt、公司流程图框线铺满、HTML 杂志排版、段落说明书、假水印（如「豆包AI生成」）。

## 结构（学 Fish，改成像素）

每张说明图必须同时有：

1. **大标题**（这张图在回答什么）
2. **3–5 个编号步骤或左右清单**
3. **每一步：短句 + 角色正在做的动作 + 看得见的物件**
4. **箭头或明确的 ①→②→③**（不能只靠「并排放着」让人猜）

推荐两种构图：

### A. 纵向清单（最像 Fish「最终你会拿到什么」）

**一行一步，1:1 对应。** 禁止左边 1、2、3 三条箭头一起扎进右边同一块大图。

从上到下 3–5 行，每行自己的格子：

`① 短句标题  →  这一步专属小场景（只画这一件成品）`

例：

1. 1张角色锚点 → **白底全身立绘**（像干净参考图，不是场景插画）
2. 可选三视图 → **正面+侧面+背面三个小人**，不要和全身锚点挤在同一框
3. 16:9长文套图 → **一张很扁的横图**（封面暖色场景）+ 旁边 1–2 张白底小横图；形状必须是 16:9，禁止用方形头像冒充
4. 3:4知识卡片 → **竖卡**，卡上能看出角色+短标签，不是空白厚纸堆
5. 换主题还能继续用 → 同一角色走进**另一个小场景**（书桌/新主题）

### B. 左右对照（提供 vs 得到）

中间一根清晰大箭头。

左「你提供」列出**具体物件名牌**（每条只出现一次，贴在对的物件上）：

- 真人照 / 宠物 / 表情包 → 看起来像**照片/表情包原图**，不要画成已经做好的像素立绘
- 文章或知识观点 → 文稿/笔记本
- Logo / 场景描述（可选） → 小 Logo 或场景缩略图

右「你得到」列出**具体成品名牌**（每条一次，形状要对上）：

- 像素角色全身+半身 → 白底全身 + 白底半身，两张小卡
- 16:9 封面+正文 → **扁的横图**，不要方形头像，不要一本合上的书
- 3:4 知识卡 → **竖卡**，卡上有角色和短字
- 同一角色可反复用 → 写在页脚即可，不必再复制一遍标签

角色左边正在把素材放进托盘，右边正在举起成品。左右动作必须不一样。

禁止：同一句标签复制两次；箭头/引线交叉；用像素成品冒充「你提供」的照片。

## 文字预算（本模式专用）

- 大标题：中文 ≤16 字，或短英文（PIXEL IP / HOW TO）
- 每一步标题：① + **6–16 个中文字**，必须是完整短句，禁止只写「素材」「确认」「出图」这种两字
- 物件名牌：贴在物件上，2–8 字，**字要大**（大约有角色头那么高），不要指甲盖小字
- 全图文字块：5–12 条；宁可少步骤、把字写大，也不要 20 条蚊子字
- 禁止：段落、长定义、把 README 整段印进图里

中文在像素里容易糊。所以：**字少而大，句子完整，不要又小又碎。**

## 角色动作（硬规则）

每一步必须换：

- 姿态（蹲、递、盖章、举起、走进）
- 手里的物件

禁止：

- 全程站直指软木板 / 指便利贴
- 三个分身下半身一模一样，只换手势
- 只比赞、只站着举一张风景照（看不出是本 skill 的成品）
- 得到侧画成无关风景画或 MINDSET/FOCUS 这种假英文卡

「得到」必须能认出是：**这个像素角色自己 + 16:9 配图 + 3:4 卡片**。

## 物件形状锁（说明图专用）

| 名牌 | 必须长这样 | 禁止长这样 |
|---|---|---|
| 角色锚点 / 全身+半身 | 白底立绘，全身一张、半身一张 | 场景插画、风景照 |
| 三视图 | 正面+侧面+背面三个小人 | 和锚点挤在同一个大框里 |
| 16:9 套图 | 很扁的横构图，能看出封面场景 | 方形头像、合上的书 |
| 3:4 知识卡 | 竖卡，卡里有角色+短标签 | 空白厚纸堆、只有图标的黄卡 |
| 你提供的照片/表情包 | 像照片、拍立得、贴纸 | 已经是成品像素角色肖像 |

## 画幅

- README / 长图介绍：默认 **16:9**
- 小红书说明页：可用 **3:4**，结构相同，步骤可压到 3–4 步

背景：暖色纸板/浅木桌（说明图需要一点「板」来挂编号块）。不要纯白空荡荡只站两个人。

## 生成前 checklist

- [ ] 这张是说明图，不是迷你剧场概念图
- [ ] 有标题，有 ①②③ 或箭头
- [ ] 每步短句完整；**一步一个格子**，没有三条箭头扎进同一块图
- [ ] 标签和物件 1:1，没有重复标签，没有「16:9」贴在方头像上
- [ ] 「提供」侧看起来像照片/文稿/Logo，「得到」侧才是像素成品
- [ ] 角色每步都在做事，不是讲解员
- [ ] 字够大
