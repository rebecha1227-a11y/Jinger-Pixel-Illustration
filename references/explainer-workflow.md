# 清单 / 介绍页怎么写进 prompt

当**这一张的内容**就是在列步骤、清点成品、对比输入/输出时，用下面的排法写进生图 prompt。

若这一张是在演戏、介绍一个概念、画一串动作：不要用这种排法。把动作、物件、少量标签写进 prompt 即可，见 `article-workflow.md` / `prompt-templates.md` 的迷你剧场写法。

选哪种排法，看这一张要让人看懂什么，写进 prompt；不是系统里有一个默认开关。

Fish 类说明图能看懂，是因为**信息设计**，不是因为简笔画更好看。我们学它的结构，不学它的 doodle 画风。

## 和另外两种模式的差别

| | 长文正文（迷你剧场） | 知识卡片 | **流程说明图（本文件）** |
|---|---|---|---|
| 目的 | 讲清一个观点 | 一页一个知识点 | 让人看懂步骤或清单 |
| 文字 | 极少，2–6 字 | 短句，见卡片预算 | **编号短句 + 物件名牌**，必须够读 |
| 箭头/序号 | 尽量少 | 步骤页可用 | **必须有 ①②③ 或箭头** |
| 角色 | 演这一个观点，去掉人图就不成立 | 和文字互动 | **可选点缀**：字大、人小；能用文字/表格/箭头/图标说清，就不必每格都有人 |
| 失败样 | — | HTML 海报 | 呆站指板子；字太小；每格都塞一个大人；只有两字标签 |

仍禁止：PPT SmartArt、公司流程图框线铺满、HTML 杂志排版、段落说明书、假水印（如「豆包AI生成」）。

## 结构（学 Fish，改成像素）

每张说明图必须同时有：

1. **大标题**（这张图在回答什么）
2. **3–5 个编号步骤或左右清单**
3. **每一步：完整短句 + 对得上的图标/物件**（角色可选，不是每格必备）
4. **箭头或明确的 ①→②→③**（不能只靠「并排放着」让人猜）

信息设计优先：先排编号、箭头、名牌、对比，再决定人要不要出场。

推荐两种构图：

### A. 纵向清单

**一行一步，1:1 对应。** 禁止左边 1、2、3 三条箭头一起扎进右边同一块大图。

从上到下 3–5 行，每行自己的格子：

`① 短句标题  →  这一步专属小图标或小场景（只画这一件）`

若用了 ①②③④：整张序号只出现一轮，不要每一行都把全套序号再画一遍。

### B. 左右对照（输入 vs 输出 / 之前 vs 之后）

中间一根清晰大箭头。

左、右都列出**具体物件名牌**（每条只出现一次，贴在对的物件上）。  
可选项写成 `A / B / C`（斜杠两边留空格），不要连成一串。  
缩进格子里的小预览图（扁横图、竖卡等）必须**完全落在框内**，留一点内边距。

禁止：同一句标签复制两次；箭头/引线交叉；用「已经做好的成品」冒充「用户提供的原材料」。

## 文字预算（本模式专用）

- 大标题：中文 ≤16 字，或短英文
- 每一步标题：① + **6–16 个中文字**，必须是完整短句，禁止只写两个字的碎标签
- 物件名牌：贴在物件上，2–8 字，**字要大**（大约有角色头那么高），不要指甲盖小字
- 全图文字块：5–12 条；宁可少步骤、把字写大，也不要 20 条蚊子字
- 图内中文按 visual plan 的 `exact_labels` **逐字来画**，不要同义改写
- 禁止：段落、长定义、把 README 整段印进图里

中文在像素里容易糊。所以：**字少而大，句子完整，不要又小又碎。**

## 角色（说明图专用）

默认：**人小、字大**。角色是点缀，不是每格主角。

- `character_budget: none` — 纯图标 + 文字也能看懂，就不要硬塞人
- `character_budget: 1 accent` — 全图最多 1–2 处小人，占格子里的一小块
- 只有这一张本身就是在「演一个动作」时，才让角色当主角（那其实该走迷你剧场，不是本文件）

如果角色出场了：

- 不要全程站直指软木板 / 指便利贴
- 不要三个分身下半身一模一样，只换手势
- 不要只比赞、手里没有对得上的物件

不要为了「每步都有人」而牺牲字的可读性。

## 物件形状锁（说明图专用）

格子里的小图，形状要像它 pretends 的东西：

| 要表示的东西 | 必须长这样 | 禁止长这样 |
|---|---|---|
| 宽图 / 横版成品 | 很扁的横构图 | 方形头像、合上的书 |
| 竖卡 / 竖版成品 | 竖卡，卡里有字或角色 | 空白厚纸堆、只有图标的色块 |
| 用户照片 / 贴纸 / 文稿 | 像照片、拍立得、贴纸、笔记本 | 已经是成品像素肖像 |
| 角色立绘锚点 | 白底立绘 | 场景插画冒充锚点 |
| 多角度 / 三视图 | 正面+侧面+背面分开的小人 | 和主锚点挤在同一个大框里 |

画中画必须完全落在圆角框内，不要溢出边缘。

## 画幅

- 长文说明页：默认 **16:9**
- 小红书说明页：可用 **3:4**，结构相同，步骤可压到 3–4 步

背景：暖色纸板 / 浅木桌（说明图需要一点「板」来挂编号块）。不要纯白空荡荡只站两个人。  
同一篇文章里多张说明图：底色、边框、风格跟本套**正文图**统一（封面可以不同，见 `style-dna.md`）。

## 生成前 checklist

- [ ] 这张是说明图，不是迷你剧场概念图
- [ ] 有标题，有 ①②③ 或箭头
- [ ] 每步短句完整；**一步一个格子**，没有三条箭头扎进同一块图
- [ ] 标签和物件 1:1，没有重复标签，没有把「横图」画成方头像
- [ ] 字够大；角色没有撑满；不是每格都塞人
- [ ] 若有序号：整张只出现一轮，没有每行重复全套 ①②③④
- [ ] 画中画在框内；可选项用 `A / B / C`
- [ ] 图内中文和 visual plan 的 exact_labels 一致
