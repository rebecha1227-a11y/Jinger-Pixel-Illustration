# 创建 / 导入角色

没有 `confirmed` 角色时读本文件。配图前必须走完确认门闩。

禁止给使用者「启用 Jinger / 用 Jinger 体验」。Jinger 图只作 style-lock。

## A. 导入现成 IP

用户发来已有形象（像素图、插画设定板、全身/半身都算）。

1. 判断类型：
   - **已经是高清像素** → 提炼特征，补齐缺失资产（至少干净全身 + `character-spec.md` + 半身）
   - **非像素插画 / 三视图** → 以它为身份参考，转成高清像素。style-lock 用 `assets/character/jinger-pixel-bust.png` 与 `jinger-pixel-fullbody.png`，只锁颗粒和密度，**不要复制 Jinger 的脸和衣服**
   - **真人照片** → 改走 B，不要当成现成 IP
2. 一次问完：角色名、水印（可跳过，默认 `@角色名`）、气质词 3 个以内（可选）
3. 生成或补齐角色包，状态 `draft`
4. 停下来等人确认

## B. 照片创建

创建前必须把「照片要求」展示给用户。

### 照片要求

**必须**

- 只用自己的照片，或已获授权的照片；禁止明星、网图、别人的脸
- 单人；不要合影、不要宠物抢镜
- 脸清晰，五官看得见；不要重度美颜把脸磨平
- 光线均匀；不要大逆光、不要脸全黑
- 至少 1 张**正面**；能看清发型、衣服
- 尽量有 1 张**全身或膝盖以上**，能看清裤子、鞋、包、标志配件

**强烈建议再补**

- 1 张侧面
- 1 张背面（有帽子、发型、包背的尤其有用）
- 标志配件特写

**不要用**

- 墨镜完全挡住眼睛，又没有另一张露眼照片（除非墨镜就是固定造型且用户要保留）
- 强滤镜、贴纸、大水印遮脸
- 一次丢很多完全不同造型（第一版只锁这一身）

缺关键照片时：**停下来要图**，不要用一张大头照硬脑补全身。

### 一次问完的 3 件事

1. 角色名（中文或英文）
2. 水印（每张成品右下角）。没有就用 `@角色名`
3. 气质关键词 3 个以内（可选）。不猜职业、年龄、敏感属性

### 生成风格

> 高清像素角色。颗粒细，有轻微体积，像独立游戏角色立绘，不是 8-bit 大格子，不是简笔画，不是 3D 盲盒，不是写实摄影。

身份必须从照片来：脸型、五官比例、肤色、发型、发际线、体型、这一身衣服/鞋/包/帽/眼镜/耳机等可见配件。只保留照片里真实存在的标志物。

style-lock：`assets/character/jinger-pixel-bust.png` + `jinger-pixel-fullbody.png`。只学像素密度、描边、上色；不要复制 Jinger 的脸、帽、衣服。

### 角色包必须包含

| 文件 | 要求 |
|---|---|
| `character-sheet.png` | 竖版设定板：主全身 + 正面 / 左侧 / 背面 / 右侧。仅设定板可用浅底和方向标签 |
| `character-reference-clean.png` | 干净全身：纯白或透明底，单人，无标题、无边框、无四视图、无色板。以后配图的主参考 |
| `character-bust.png` | 干净半身/头肩，锁脸和头上的标志配件 |
| `character-spec.md` | 可观察特征 + 角色名 + 水印 + 气质词 + accent_colors。不写猜测信息 |
| `character.json` | 由 `scripts/character_registry.py register` 生成 |

四视图必须一致。干净参考图不得复制设定板排版。

## 确认门闩

- 展示设定板 + 干净全身 + 半身，问：确认，还是改哪一处？
- 一次只改一个主要问题
- 旧文件不覆盖，存 `-v2` `-v3`
- 未说「确认 / 定稿 / 就用这个」之前：不能配长文、不能做知识卡片、不能设为当前角色
- 同时丢了照片和文章：先创建并停在确认，不要提前配图

无生图时：仍写出 `character-spec.md` 草稿 + 三张图的 prompt + 照片检查结果，等人家出图后再 `register` / `confirm`。

## character-spec 模板

```markdown
# {角色名}

- name: {角色名}
- watermark: @{handle或角色名}
- vibe: {最多3个词}
- accent_colors: [{色1}, {色2}, {色3}]

## 锁死外观
- 脸型 / 五官：
- 肤色：
- 发型 / 发际线：
- 体型比例：
- 上衣：
- 裤子 / 裙子：
- 鞋：
- 帽 / 眼镜 / 耳机等头配件：
- 包 / 项链 / 其他标志物：

## 只允许改
动作、姿态、朝向、视线、轻微表情。

## 不允许改
脸型、发型、这一身服装与标志配件、身体比例、高清像素画风。
```
