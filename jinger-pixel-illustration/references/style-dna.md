# 视觉 DNA

## 共同

- 高清像素：颗粒细，有轻微体积和抖动阴影。不是 8-bit 大格子、不是简笔画、不是 3D 盲盒、不是写实摄影。
- 当前角色永远同一身。
- 水印：右下角，小而不抢眼，文案来自当前角色 `character-spec` 的 `watermark`。**排版叠加，禁止让 AI 画。**
- 一张图一个观点。
- 正文白底图：AI 图内最多 2–6 字短标签。
- 知识卡片 / 长文封面：允许短标题和短标签画在图里，但仍要短、少、准；不要段落。水印永远后盖。

style-lock 角色密度：`assets/character/jinger-pixel-bust.png` + `jinger-pixel-fullbody.png`（只学画风，不学 Jinger 的脸，除非当前角色就是 Jinger）。

封面/主题场景锁：`assets/style-lock/warm-pixel-scene-16x9.png`（只给封面学气质；正文图不要学它的高信息密度）。

## 长文 16:9

一套必须同时有：

1. 封面 / 主题背景 × 1
2. 正文解释图 × 按信息密度（见 `article-workflow.md`）

| 用途 | 背景 | 密度 |
|---|---|---|
| 封面 / 主题 | 暖色简单像素场景：奶油纸 / 浅木桌 / 软木板，可加深棕像素细边框；桌上 1–3 小物件 | 可稍满：人物 + 少量信息块 + 桌面 |
| 正文解释 | **默认白底迷你剧场**：白底 + 一点点像素地面/接触阴影 | 物件 1–3；主体约 50%–65% |

禁止：写实风景、完整大房间巡游、霓虹 HUD、Vox 黄黑拼贴、PPT 流程图、正文图塞成白皮书海报。

**流程拆解**（多用于正文）：3–5 节点；角色可分身，每个分身都在做事；从左到右，要透气。  
**核心动作**：一个角色 + 一个核心物件 + 一个动作 + 一个可见结果。角色必须参与核心关系，去掉角色图就不成立。

## 知识卡片 3:4

- 画幅 3:4。整张由生图模型一次画完，像一幅竖着的像素插画，不是排版海报。
- 气质对齐暖色场景锁：奶油纸 / 浅木桌 / 软木板，可加深棕细边框。
- 点缀色用该角色 `accent_colors`
- 角色必须生活在场景里，和短文字块一起演戏
- 英文像素标题仅封面 + 至多 1 张强调页；其他页短中文标签即可
- 禁止：HTML 杂志排版感、纯文字堆叠、Vox 拼贴、深色 Game Boy 整屏、PPT
